# 7.2 Agent 指令文件与自动记忆

## 这项功能是做什么的

7.2 让 Agent 在每次执行任务前自动读取当前项目里的 `AGENTS.md` / `ZZM.md` 指令文件，并把跨会话长期记忆作为可审计、可启停的上下文注入模型。它解决的是两个日常问题：项目规则需要每次手动重复说明，以及长期记忆一旦写入后用户看不清来源、也不能临时禁用。

没有这项能力时，用户需要反复告诉 Agent “这个项目怎么测试、提交前要注意什么、输出用中文、不要改某些目录”；长期记忆也只能添加和删除，无法判断某条记忆是不是正在影响当前回答。

## 具体例子

项目根目录有 `AGENTS.md`：

```text
所有代码修改后必须运行 pytest。
回答用户时使用中文。
```

子目录 `packages/api/ZZM.md`：

```text
API 包只允许修改 packages/api 内的文件。
```

用户在 `packages/api` 相关任务里输入：

```text
修复接口测试失败
```

执行链路：

1. `MemoryStore` 通过 `InstructionManager` 从 workspace root 到当前目录查找 `AGENTS.md` / `ZZM.md`。
2. 根目录指令先加载，子目录指令后加载，并带有 priority，后者代表更近目录，优先级更高。
3. 指令内容作为 system message 注入当前 Turn。
4. 语义记忆和 episodic 记忆继续按 `retrieval_top_k` 检索注入。
5. `_compression["memory_load_state"]` 记录指令文件、语义记忆、会话摘要的来源、版本和是否重复。
6. 用户可以用 `/instructions` 查看加载了哪些指令文件，用 `/semantic` 查看长期记忆，用 `/memory-disable python` 临时禁用匹配记忆。

最终模型看到的上下文会包含项目规则、自动记忆、压缩历史和当前用户输入，但这些来源是分层且可追踪的。

## 功能作用

- 自动加载 `AGENTS.md` / `ZZM.md` 项目指令文件；
- 支持从 workspace root 到当前目录的层级加载，近目录指令优先级更高；
- 对指令文件设置字符预算，超出后截断并在上下文里标记；
- 长期语义记忆带 `source` 和 `enabled` 元数据；
- 禁用的语义记忆不会注入模型，但仍可通过 `/semantic` 查看；
- CLI 提供 `/instructions`、`/memory-disable`、`/memory-enable`；
- `/config` 能显示 `memory.instruction_files`、`memory.instruction_max_chars` 和 `memory.auto_memory_enabled`。

## 对应代码文件

- `zzm_agent/memory/instructions.py`
  - `InstructionManager`：发现并加载指令文件；
  - `InstructionFile`：记录路径、优先级、截断状态、版本和内容。
- `zzm_agent/memory/store.py`
  - `build_instruction_messages()`：把项目指令转换为 system message；
  - `list_instruction_files()`：给 CLI 展示加载来源；
  - `build_turn_messages()`：把指令文件和自动记忆一起接入 Turn 上下文；
  - `set_memory_enabled()`：启用或禁用匹配的语义记忆。
- `zzm_agent/memory/semantic_store.py`
  - `remember()`：写入 `source` 和 `enabled`；
  - `load(include_disabled=...)`：按需包含禁用记忆；
  - `set_enabled()`：修改记忆启用状态。
- `zzm_agent/cli_support/commands.py`
  - `/instructions`、`/memory-disable`、`/memory-enable`、增强 `/semantic` 和 `/config`。
- `zzm_agent/cli_support/rendering.py`
  - slash completion 和 help 文案。
- `zzm_agent/cli_support/runtime.py`
  - 把配置里的指令文件和自动记忆参数传给 `MemoryStore`。
- `config.yaml`
  - 新增 `memory.instruction_files`、`memory.instruction_max_chars`、`memory.auto_memory_enabled`。

## 关键事件或数据结构

- `InstructionFile`
  - `path`：指令文件路径；
  - `name`：文件名，例如 `AGENTS.md`；
  - `priority`：加载优先级，越靠近当前目录优先级越高；
  - `truncated` / `original_chars` / `loaded_chars`：预算和截断信息；
  - `version`：由 mtime 和 size 组成，用于恢复和审计。
- `MemoryLoadState`
  - `sources` 会记录 `project_instruction`、`semantic`、`episodic` 等来源；
  - `memory_file_versions` 记录指令文件和记忆文件版本；
  - `duplicate_sources` 记录重复注入来源。
- 语义记忆 entry
  - `fact`：记忆文本；
  - `source`：来源，当前手动 `/remember` 默认是 `manual`；
  - `enabled`：是否参与后续上下文注入；
  - `created_at` / `updated_at`：审计时间。

## 执行链路

```text
用户输入
→ AgentLoop.run()
→ MemoryStore.build_turn_messages()
→ build_memory_messages() 检索启用的语义/episodic 记忆
→ build_instruction_messages() 加载 AGENTS.md / ZZM.md
→ MemoryLoadState 记录来源、版本、截断和重复信息
→ ConversationMessageStore.begin_turn()
→ 模型看到 system prompt + 项目指令 + 自动记忆 + 压缩历史 + 当前用户输入
```

CLI 查看链路：

```text
/instructions
→ MemoryStore.list_instruction_files()
→ InstructionManager.load()
→ 输出 priority、文件名、路径、截断信息
```

记忆禁用链路：

```text
/memory-disable python
→ MemoryStore.set_memory_enabled("python", False)
→ SemanticStore.set_enabled()
→ 后续 build_memory_messages() 不再注入 disabled 记忆
```

## 边界和非目标

- 7.2 不做 Skills 引用文件的渐进式加载，那个属于 P4；
- 7.2 不做复杂 Token 分区预算，只提供指令文件字符预算，完整预算治理在 8.5；
- 自动记忆不会静默覆盖 `AGENTS.md` / `ZZM.md`，项目指令和长期记忆是不同来源；
- 禁用记忆不是删除，删除仍使用 `/forget <keyword>`。
