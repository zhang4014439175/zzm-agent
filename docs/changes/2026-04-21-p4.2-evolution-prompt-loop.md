# Change Summary: Implement P4.2 Evolution Prompt Loop

**Date**: 2026-04-21  
**Identifier**: p4.2-evolution-prompt-loop

## 1. Problem Statement

`/evolve` could evaluate recent conversation history, but prompt optimization was still a stub and there was no explicit run / diff / apply / rollback workflow. This made prompt changes either impossible or unsafe to apply because the user could not review a candidate before mutating `config.yaml`.

## 2. Technical Solution

### 2.1 Candidate Generation
- Added `EvolutionOptimizer.run()` to generate a pending prompt candidate from the current prompt, recent history, and latest evaluation context.
- Candidate generation stores records under `.zzm_agent/evolution/candidates.json`.
- `/evolve` remains a compatibility alias for `/evolve run`, but it no longer applies changes automatically.

### 2.2 Review and Apply Flow
- Added `EvolutionOptimizer.diff()` for unified prompt diffs.
- Added `EvolutionOptimizer.apply_candidate()` to explicitly apply a pending candidate as runtime active prompt state.
- Added `EvolutionOptimizer.rollback()` to restore the latest rollback point as runtime active prompt state.
- Added prompt history persistence under `.zzm_agent/evolution/prompt_history.json`, capped by `evolution.history_versions`.
- Added active prompt persistence under `.zzm_agent/evolution/active_prompt.json`; `config.yaml` remains the immutable baseline during interactive evolution.
- Prompt history now records whether a rollback point came from `config` or the previous `active` prompt, and repeated identical rollback points are de-duplicated.

### 2.3 CLI Integration
- Added `/evolve run`.
- Added `/evolve diff [candidate-id]`.
- Added `/evolve apply [candidate-id]`.
- Added `/evolve rollback`.
- Updated `/help` output to show the explicit evolve subcommands.

## 3. Validation Results

### 3.1 Automated Tests
- Added optimizer tests for candidate generation, diff, apply, rollback, and prompt history.
- Added CLI tests for `/evolve run`, `/evolve diff`, `/evolve apply`, and `/evolve rollback`.
- Updated constants coverage for new evolution persistence paths.
