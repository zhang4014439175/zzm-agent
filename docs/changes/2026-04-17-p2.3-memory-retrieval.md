# P2.3 记忆检索

## 背景

`P2.1` 已经具备 `semantic` 和 `episodic` 两层长期记忆，但运行时注入仍然主要按“最近项”处理，没有基于当前用户问题做相关记忆检索，也没有提供显式的 `/search` 命令查看命中结果。

按 `docs/superpowers/specs/2026-04-10-zzm-agent-v2-requirements.md` 的定义，`P2.3` 需要补齐：

- 关键词检索 `episodic` 与 `semantic`
- 支持 `memory.retrieval_top_k`
- 提供 `/search <keyword>`
- 预留 `MemoryRetriever` 接口

## 本次改动

### 1. 新增检索接口

新增 [retriever.py](/Users/zhangzhiming/project/study2026/zzm-agent/zzm_agent/memory/retriever.py)，定义：

- `MemoryRetriever` 抽象接口
- `KeywordMemoryRetriever` 默认实现

当前默认实现基于：

- query 整体子串命中
- query 拆词后的关键词包含匹配
- `updated_at` 作为同分时的次排序条件

### 2. 在 MemoryStore 中接入检索

更新 [store.py](/Users/zhangzhiming/project/study2026/zzm-agent/zzm_agent/memory/store.py)：

- 新增 `search_memories(keyword, limit=None)`
- `build_memory_messages()` 增加 `query` 参数
- `build_turn_messages()` 改为按 `user_input` 检索长期记忆后再注入上下文

兼容策略：

- 如果显式不传 `query`，仍可保持原来的“按最近项截断”行为
- 如果传入 `query`，优先走关键词检索

### 3. 新增 `/search` 命令

更新 [commands.py](/Users/zhangzhiming/project/study2026/zzm-agent/zzm_agent/cli_support/commands.py)：

- 新增 `/search <keyword>`
- 输出 semantic 与 episodic 的命中结果
- `/help` 同步增加 `/search`

### 4. 同步规格文档状态

更新 [requirements.md](/Users/zhangzhiming/project/study2026/zzm-agent/docs/superpowers/specs/2026-04-10-zzm-agent-v2-requirements.md)：

- 把 `P3.1` 状态同步为已完成
- 把 `P2.3` 改为进行中 `[-]`
- 把 `/search`、retrieval 测试状态同步到当前真实进度
