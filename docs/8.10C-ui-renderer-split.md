# 8.10C UI 与 Renderer 目录拆分

## 1. 一句话说明

把 CLI 输入、补全、Renderer 和主题能力迁入 cli_support/ui/ 分层目录，并保留原 rendering.py 兼容入口。

## 2. 为什么需要它

原 rendering.py 同时处理终端主题探测、输入、Slash 补全、Markdown、工具事件流和欢迎界面，任何 UI 修改都要加载整份文件。新的目录边界让输入、补全、渲染器和主题可以独立替换，也为未来非阻塞 TUI 留出清晰扩展点。

## 3. 一个实际使用例子

用户运行 zzm-agent repl 后，ui.theme 创建终端 Console，ui.input 创建底部输入区，ui.completion 提供 Slash 命令补全，ui.renderers 将模型流事件和工具结果展示在 transcript 中。旧插件继续从 cli_support.rendering 导入 render_notification 也能正常工作。

## 4. 功能的大致流程

1. bootstrap 通过主题模块创建 Console。
2. REPL 通过输入模块建立 PromptSession 并读取用户输入。
3. completion 模块匹配 Slash Command 并控制补全菜单。
4. renderers 模块消费模型流事件、工具结果和通知。
5. rendering.py 将旧导入透明转发到 ui/ 实现。

## 5. 开发前和开发后的区别

开发前所有 UI 能力位于一个约 1200 行文件。开发后公共能力按 input.py、completion.py、renderers/ 和 theme.py 暴露，旧文件只承担兼容转发，因此调用方可以逐步切换而无需一次修改全部插件。

## 6. 现在已经支持的能力

- 独立导入终端主题与 Console 构造。
- 独立导入 PromptSession、底部工具栏和输入读取。
- 独立导入 Slash Command Completer 与 Lexer。
- 独立导入 Markdown、纯文本和终端流式 Renderer。
- 保留通知、错误卡片、帮助和欢迎界面。
- 保留 cli_support.rendering 的公开及历史私有兼容入口。

## 7. 当前限制（还做不到什么）

当前仍是同步 REPL 终端 UI，不包含固定底部输入框、可滚动 transcript 和运行中继续输入等非阻塞 TUI 能力；这些属于 roadmap 后续 TUI 阶段。

## 8. 给开发者看的实现位置

- zzm_agent/cli_support/ui/input.py：输入与 PromptSession。
- zzm_agent/cli_support/ui/completion.py：Slash 补全与 Lexer。
- zzm_agent/cli_support/ui/renderers/__init__.py：Renderer 和展示入口。
- zzm_agent/cli_support/ui/theme.py：Console 与主题。
- zzm_agent/cli_support/ui/legacy.py：共享兼容实现。
- zzm_agent/cli_support/rendering.py：旧路径兼容门面。
- tests/test_cli_directory_splits.py：目录与类型身份测试。

## 9. 测试如何证明它有效

目录拆分测试验证旧 rendering 入口与新 input、completion、renderers、theme 模块保持同一对象身份，避免类型判断和 monkeypatch 失效。原 CLI 测试继续覆盖补全、输入、状态栏、流式 Renderer、工具展示、帮助和欢迎界面。

## 10. 浅色终端对比度修复

终端背景探测按“`ZZM_AGENT_TERMINAL_THEME` 显式覆盖 → `COLORFGBG` → Windows
控制台缓冲区 → Windows 应用主题”的顺序执行。系统使用深色主题但终端 Profile
使用白色背景时，不再误选 Monokai 的浅色命令文字。Agent Markdown 代码块、帮助
命令列、输入命令和补全选中项共享高对比调色板。

自动探测受终端实现限制时，可以在启动前强制指定：

```powershell
$env:ZZM_AGENT_TERMINAL_THEME = "light"
zzm-agent repl
```

`tests/test_cli_ui_rendering.py` 覆盖终端信号优先级、白底命令代码块深色前景，以及
背景误判时不强制白色文本；CLI 定向回归 `93 passed`，全量回归
`416 passed, 2 skipped`。
