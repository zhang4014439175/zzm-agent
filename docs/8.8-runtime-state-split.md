# 8.8 RuntimeState 拆分

## 目标

把集中在 `core/runtime_state.py` 中的运行时状态按生命周期和所有权拆分，同时保持原导入路径、状态转换、序列化字段与恢复行为兼容。

## 完成内容

- `state/application.py`：定义进程级 `ApplicationState`。
- `state/conversation.py`：定义会话级 `ConversationState`。
- `state/turn.py`：定义 `TurnState`、`TurnStatus` 和统一终止记录 `TurnTermination`。
- `state/loop.py`：定义 `LoopState`、阶段、转换原因与转换校验。
- `state/permission.py`：定义权限请求、决定、作用域和 `PermissionState`。
- `state/cancellation.py`：定义层级取消令牌、异常和控制器。
- `state/support.py`：承接原文件中不属于六类核心状态的 FileStateCache 与 MemoryLoadState，避免继续把辅助状态塞回兼容门面实现。
- `state/__init__.py`：提供新状态包的统一公开入口。
- `core/runtime_state.py`：缩减为兼容导出门面，旧 import 返回新模块定义的同一个类对象。

## 依赖迁移

核心运行代码已改为从 `core.state` 或具体子模块导入状态对象，包括 AgentLoop、QueryEngine、Segment、ToolCallCoordinator、MemoryStore 和文件工具。原 `core.runtime_state` 路径只为现有外部调用方和旧测试保留。

## 兼容性

- `from zzm_agent.core.runtime_state import TurnState` 等旧导入继续有效。
- 兼容门面与新模块导出保持对象身份一致，没有引入兼容子类。
- `to_record()` / `from_record()` 的字段、默认值和嵌套恢复类型保持不变。
- 状态阶段、转换原因、权限作用域和取消传播语义保持不变。

## 验收

- 新增模块归属、兼容对象身份和嵌套序列化往返测试。
- 状态生命周期、状态序列化与 Replay 定向测试通过。
- 完整测试套件通过。
- `git diff --check` 无格式错误。
