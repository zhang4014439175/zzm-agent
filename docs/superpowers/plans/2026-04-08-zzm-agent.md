# zzm-agent 任务计划 (分阶段详细清单)

**Goal:** 基于 OpenAI 兼容接口 de 个人 AI Agent，支持 tool_calling、插件系统、持久记忆、CLI 界面和自我进化框架。

**Tech Stack:** Python 3.11+, openai SDK, pyyaml, rich, pytest

**使用方式:** 每次打开 Claude 说「下一个任务」，Claude 找到第一个 `- [ ]` 执行并标记为 `- [x]`。
**执行规则:** 每次执行前必须询问用户：
1. **完成此阶段所有任务** (例如 P2)
2. **仅完成下一项任务** (例如 M08)
3. **取消执行** (No)
执行完选定内容后必须停止，不得自动继续下一项。

**实现约束:** 
- 当前版本按 MVP 执行，不要求插件热重载、不要求 session 级记忆检索。
- `ToolRegistry` 必须保持单一注册来源，避免全局 registry 与局部 registry 并存。
- **生成的代码必须包含详细的注释**，解释核心逻辑、参数含义及返回值，确保可读性。

**安全约束:** 
- `shell.py` 和 `file_ops.py` 仅按本地可信环境实现，不视为可直接对外暴露的生产能力。
- 若扩展为多用户模式，必须补充权限校验、沙箱隔离及审计能力。
